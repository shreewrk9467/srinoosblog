## Slide 2: 1. Claude-Mem — Cross-Session Persistent Memory
- **Core Capability:** Semantic vector database and SQLite storage for past architectural decisions.
- **Why It Matters:** Defeats agent amnesia across sessions and restarts.
- **Workflow:** Lifecycle hooks index every bug discovery, database schema, and convention automatically.

## Slide 3: 2. GSD Core — Spec-Driven Anti-Rot Development
- **Core Capability:** 5-step phase loop (Discuss → Plan → Execute → Verify → Ship).
- **Why It Matters:** Eliminates token bloat on multi-hour projects by deploying fresh subagents.
- **Workflow:** Lightweight markdown roadmaps in `.planning/` with atomic, verified git commits.

## Slide 4: 3. Agent-Reach — Zero-Fee Real-Time Web Research
- **Core Capability:** Universal CLI scrapers for Reddit, YouTube transcripts, X, and GitHub.
- **Why It Matters:** Zero expensive API subscriptions needed to gather community sentiment and documentation.
- **Workflow:** Native Jina Reader cleans web documentation into high-density Markdown.

## Slide 6: 5. PPT Master — Editable PowerPoint Generation
- **Core Capability:** Compiles Markdown notes into native, styled vector slides (`.pptx`).
- **Why It Matters:** Produces professional editable slide decks rather than flat image screenshots.

- **Workflow:** ElevenLabs word-level cutpoints combined with FFmpeg filters.
